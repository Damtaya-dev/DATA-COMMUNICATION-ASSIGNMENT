01

Data Communication & Its Components

Data communication is the process of exchanging data between devices through a transmission medium. The five core components are: the message (the information itself), the sender (source device), the receiver (destination device), the transmission medium (cable, air, fiber), and the protocol (agreed rules governing communication). Without all five, reliable data exchange breaks down. Protocols ensure both parties speak the same language — regardless of manufacturer or operating system.

02

Morse Code

Invented by Samuel Morse and Alfred Vail in the 1830s, Morse code encodes text as sequences of short (dots) and long (dashes) signals. It was the first practical digital encoding system, transmitting messages over telegraph wires at speeds impossible for a horse or ship. Every letter and numeral has a unique pattern — "SOS" (· · · — — — · · ·) became the universal distress call. Morse code proved that a binary-like system could carry rich information over simple electrical pulses — a concept that underpins modern digital communication.

03

Satellites

Communication satellites relay signals between ground stations, enabling telephone calls, internet access, GPS, weather forecasting, and TV broadcasts across continents. They orbit at different altitudes: LEO (Low Earth Orbit, ~500–2,000 km) offers low latency used by Starlink; MEO (~5,000–20,000 km) hosts GPS constellations; and GEO (Geostationary, ~36,000 km) keeps satellites fixed over a point — ideal for TV and weather. A satellite receives an uplink signal, amplifies it, shifts its frequency, and retransmits it as a downlink, all within milliseconds.

04

Networking & Layers

Computer networks are organized in layers to separate concerns and allow interoperability. Each layer provides services to the one above it and uses services from the one below it. This layered approach means a change in the physical medium (say, switching from copper to fiber) doesn't require rewriting application software. Networks can be classified by size — PAN, LAN, MAN, WAN — and by topology: bus, star, ring, mesh. Protocols like TCP/IP govern how packets are addressed, routed, and delivered reliably across diverse network types.

05

The OSI Model

The Open Systems Interconnection (OSI) model, developed by ISO in 1984, provides a universal framework describing how different network systems communicate. Its seven layers each handle a specific aspect of data transmission:

# Layer Function Example Protocols / Devices
7 Application User-facing network services HTTP, FTP, DNS, SMTP
6 Presentation Data translation, encryption, compression SSL/TLS, JPEG, ASCII
5 Session Establishes, manages, terminates sessions NetBIOS, RPC
4 Transport End-to-end delivery, error recovery TCP, UDP
3 Network Logical addressing and routing IP, ICMP, Routers
2 Data Link MAC addressing, framing, error detection Ethernet, Wi-Fi, Switches
1 Physical Raw bit transmission over medium Cables, Hubs, Radio waves
